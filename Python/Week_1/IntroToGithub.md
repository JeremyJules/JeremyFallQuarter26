1. What is Git, what is Github, and what is the difference between the two?
Git is a time machine for your project tracking your changes and makes save files, while
GitHub is a website built around git that you can use to share, collaborate, or store projects.
2. What is the difference between a local repository and a remote repository?
Local repo is only on your device, while a Remote repo is on the internet
3. What does the push command do in Git?
upload files into my remote repo from your local repo
4. What does the commit command do in Git?
Saves your files into your local repo
5. What is Github Desktop, & why are we using it?
Github Desktop is a desktop app used to simplify Git and GitHub when using them.
